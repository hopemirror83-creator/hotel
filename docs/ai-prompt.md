# AI 콘텐츠 생성 프롬프트 설계

## 입력 데이터

- 아고다 기본 정보: 호텔명, 별점, 평점, 후기 수, 가격, 편의정보, 예약 URL
- 네이버 검색 결과: 제목과 요약만 사용
- 지도 정보: 주소, 좌표, 주변 지역 신호
- 수동 보정 정보: 주소, 좌표, 운영자가 입력한 확인 메모

## 금지

- 아고다 후기 원문 저장
- 아고다 후기 원문 출력
- 검색 결과 문장 그대로 복사
- 출처 문장과 유사한 긴 문장 생성

## 출력 형식

반드시 JSON만 출력한다.

```json
{
  "summary": "",
  "pros": [],
  "cons": [],
  "recommended_for": [],
  "not_recommended_for": [],
  "check_points": [],
  "seo_title": "",
  "meta_description": ""
}
```

## 품질 요청

- 호텔마다 다른 장점과 단점이 드러나야 한다.
- 단정하지 말고 "반복적으로 언급됩니다", "확인하는 편이 좋습니다"처럼 예약 전 판단 문체를 사용한다.
- SEO 키워드는 자연스럽게 포함하고 반복하지 않는다.
